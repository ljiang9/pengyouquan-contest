# 朋友圈摄影大赛 📸

7 天国庆假期，朋友圈摄影大赛开赛——集赞数就是 GDP！

## 玩法

- 7 天假期，每天从 3 张候选照片里选 1 张"今日最佳"发朋友圈
- 每张照片有三维属性：**颜值 / 逼格 / 烟火气**
- 5 大好友群体点赞偏好各不相同：
  - 爸妈团（30 人）爱烟火气
  - 文青圈（25 人）爱逼格
  - 颜狗团（35 人）爱颜值
  - 干饭人（40 人）偏爱烟火气
  - 夜猫子（20 人）颜值逼格双修
- 发布时间也有讲究，选对时段对应群体点赞 **x1.5**：
  - 早上 8 点 → 爸妈团在线
  - 中午 12 点 → 干饭人在线
  - 晚上 9 点 → 夜猫子在线
- 每日随机事件：被赞爆上热门（赞数 x2）、P 过头被认出（社死，赞数清零）、忘屏蔽老板（emo，赞数 x0.5）
- 7 天后按总赞数授称号：朋友圈之王 / 点赞收割机 / 透明人 / 分组可见受害者，附善意玩梗评语

## 运行

```bash
python3 -m pengyouquan_contest              # 交互模式（需要终端）
python3 -m pengyouquan_contest --auto --games 10 --seed 42   # AI 自动演示
python3 -m pengyouquan_contest --auto --games 1 --seed 7 --verbose  # 看单局战报
```

纯 Python 标准库（argparse/random/sys），Python 3.10+。

## 玩梗声明

本项目致敬国庆假期"朋友圈摄影大赛""集赞"等网络玩梗文化，全部内容为原创虚构，
照片名称、好友群体、事件文案均为程序生成，与任何真实人物、平台无关，纯属娱乐。

## 真实验证记录

- `py_compile` 双文件通过
- 单元测试 18 项全过：时段加成系数整数精确断言（烟火气 100 的照片早上 8 点发 6150 赞 vs 晚上 9 点发 5300 赞）、
  P 过头清零、上热门 x2、忘屏蔽老板 x0.5、非法照片/时段/编号抛 `IllegalMove`、
  4 档称号边界、同种子可复现、AI 选择合法、每日候选不重名
- `--auto --games 10 --seed 42` 正常结束；50 局分布：朋友圈之王 1 / 点赞收割机 33 / 透明人 16
- 同种子两次运行输出逐字节一致；非 tty 运行中文提示并退出码 2

## 已知局限（诚实版）

- 点赞数、群体人数、事件概率均为拍脑袋设定的游戏数值，不反映任何真实社交平台算法
- AI 是按期望点赞的贪心选择（永远选中午 12 点干饭人档），非最优策略
- "分组可见受害者"称号在自动演示中极难出现（靠单元测试直接验证 `settle(0)`）
- 纯文本界面，无图形/存档；照片为文字描述，无真实图片
